# Киносоветник

Рекомендательная система фильмов, которая подбирает персонализированные рекомендации на основе предпочтений пользователей, истории оценок и характеристик фильмов, а также позволяет оценивать качество работы алгоритмов рекомендаций.

## О проекте

«Киносоветник» — проект по разработке интеллектуальной рекомендательной системы, предназначенной для подбора фильмов с учётом индивидуальных предпочтений пользователей.

Пользователь может выбирать любимые жанры, оценивать фильмы, ставить лайки и пропуски. На основе этих данных система формирует персональную подборку фильмов.

В проекте реализованы четыре алгоритма рекомендаций:

- **Popularity-based** — рекомендации на основе популярности и пользовательских оценок.
- **Content-based** — подбор фильмов по сходству жанров, названий, описаний и слоганов с использованием TF-IDF.
- **Collaborative Filtering** — рекомендации на основе сходства пользовательских оценок фильмов (item-item).
- **Hybrid** — комбинирование нескольких алгоритмов для формирования итогового рейтинга рекомендаций.

Также реализована система оценки качества моделей, позволяющая сравнивать алгоритмы по шести метрикам и анализировать результаты с помощью графиков, таблиц и доверительных интервалов.

## Функциональность

- Каталог из 10 000 фильмов.
- Персональные рекомендации на основе предпочтений пользователей.
- Четыре алгоритма рекомендательной системы.
- REST API для взаимодействия с системой.
- История пользовательских оценок и действий.
- Аналитика каталога фильмов.
- Сравнение алгоритмов рекомендаций по шести метрикам.
- Визуализация результатов экспериментов и 95% доверительных интервалов.
- Сохранение истории запусков оценки качества моделей.

## Результаты эксперимента

Для оценки качества рекомендательных алгоритмов проведён эксперимент со следующими параметрами:

- 300 пользователей.
- 12 000 пользовательских оценок.
- 30% оценок каждого пользователя использованы в качестве тестовой выборки.
- Размер рекомендательной выдачи: K = 10.
- Критерий положительной оценки фильма: рейтинг 4 и выше.
- Сравнение четырёх алгоритмов с базовой случайной моделью.

### Сравнение моделей

| Модель | Precision@10 | Recall@10 | NDCG@10 | Hit Rate@10 | MAP@10 | MRR |
|---|---:|---:|---:|---:|---:|---:|
| **Content-based** | **0,038** | **0,234** | **0,122** | **0,332** | **0,076** | **0,100** |
| Hybrid | 0,034 | 0,206 | 0,110 | 0,300 | 0,069 | 0,092 |
| Collaborative Filtering | 0,021 | 0,131 | 0,068 | 0,196 | 0,040 | 0,060 |
| Popularity-based | 0,020 | 0,098 | 0,052 | 0,179 | 0,029 | 0,051 |
| Random Baseline | 0,015 | 0,089 | 0,045 | 0,139 | 0,026 | 0,038 |

### Ключевые результаты

- **NDCG@10 = 0,122** — показатель качества ранжирования Content-based модели, в 2,7 раза превышающий результат случайной базовой модели.
- **Hit Rate@10 = 0,332** — как минимум один понравившийся фильм присутствует в рекомендованной десятке у 33,2% пользователей.
- **Recall@10 = 0,234** — модель находит 23,4% понравившихся фильмов из тестовой выборки.
- **MAP@10 = 0,076** — средняя точность ранжирования рекомендаций.
- **MRR = 0,100** — показатель позиции первого релевантного фильма в рекомендательном списке.

По результатам эксперимента Content-based показала наибольшие значения всех шести метрик среди сравниваемых алгоритмов. Hybrid продемонстрировала близкие результаты по основным показателям качества рекомендаций.

### Метрики оценки

| Метрика | Описание |
|---|---|
| Precision@K | Доля релевантных фильмов среди рекомендованных |
| Recall@K | Доля найденных релевантных фильмов от общего числа |
| NDCG@K | Качество ранжирования с учётом позиции релевантных фильмов |
| Hit Rate@K | Доля пользователей, получивших хотя бы одну релевантную рекомендацию |
| MAP@K | Средняя точность рекомендаций с учётом позиций попаданий |
| MRR | Обратная позиция первого релевантного фильма |

Для каждой метрики рассчитываются 95% доверительные интервалы, позволяющие анализировать статистическую устойчивость результатов и сравнивать алгоритмы между собой.

## Итог

В рамках проекта разработана полноценная рекомендательная система фильмов с несколькими алгоритмами персонализации, REST API, пользовательским интерфейсом и инструментами аналитики.

Реализован экспериментальный контур для количественной оценки качества рекомендаций, сравнения моделей и визуализации результатов.

Проект объединяет разработку backend-системы, работу с базами данных, методы машинного обучения, рекомендательные алгоритмы и анализ качества ML-моделей.
